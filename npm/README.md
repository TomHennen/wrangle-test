# wrangle-test-npm-fixture

> **Do not depend on this package.**

A disposable npm fixture used to integration-test
[wrangle](https://github.com/TomHennen/wrangle)'s `build_and_publish_npm.yml`
reusable workflow. It is built, tested, and published by
`wrangle-test`'s showcase workflow as a worked example of wrangle's
npm build path (SBOM, SLSA L3 provenance, `npm publish --provenance`).

Versions are rotated without notice. No external consumer may depend on
this package.
